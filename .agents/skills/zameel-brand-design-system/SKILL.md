# Zameel Brand Identity & UI Design System (دليل الهوية البصرية ونظام واجهات زميل)

## 1. الفلسفة وهوية العلامة التجارية (Brand Philosophy)
منصة "زميل" تمثل السوق الجامعي الذكي لتبادل المستلزمات والمقررات والمعدات الدراسية يداً بيد بين الطلاب داخل الحرم الجامعي.
- **الابتعاد عن القوالب التقليدية:** نبتعد تماماً عن الرموز المستهلكة (كقبعات التخرج السوداء أو عربات التسوق الاستهلاكية المعتادة).
- **جوهر الهوية:** تمكين طلاب الجامعات من التواصل المباشر، التدوير والاستدامة الأكاديمية، والتسليم الآمن الفوري داخل الكلية بأسلوب تقني وعصري ممتع.

---

## 2. أيقونة الشعار والرمزية الهندسية (Brand Icon Concept)
- **حلقة التبادل بين الزملاء (Peer-Exchange Loop):**
  - دمج هندسي وانسيابي بين حرف "ز" العربي وحرف "Z" اللاتيني.
  - المسار يجسد يدين متصافحتين ومتبادلتين لكتاب أو أداة دراسية (Hand-to-Hand Exchange) بين زميلين في الحرم الجامعي.
  - اليد العلوية باللون النعناعي الكهربائي المتدرج تلتقي باليد السفلية باللون الزعفراني المتدرج لتشكيل حلقة مستمرة تمثل تدوير المعرفة والأدوات.
- **نقطة الشعار (الماسة الضوئية - Golden Diamond Dot):**
  - ماسة ذهبية براقة تعلو الشعار تمثل "نقطة حرف الزاي".
  - ترمز أيضاً إلى "نقطة اللقاء" (Campus Meeting Point) التي يجتمع عندها الزملاء لإتمام التبادل بثقة وأمان.
- **مسار ملف الأيقونة المعتمد:**
  `~/images/zameel-brand-icon.png` (أو `src/Zameel.Web/wwwroot/images/zameel-brand-icon.png`).

### تدرجات وظلال تكميلية داعمة (Complementary Neutrals):
- **السطوح البيضاء النقية:** `#FFFFFF` للبطاقات العلوية وحاويات المحتوى (`--bg-surface: #ffffff;`).
- **حدود العناصر الخفيفة:** `#E9E7E1` متناسقة مع لون ورق الألاباستر (`--border-subtle: #E9E7E1;`).
- **النصوص الأساسية:** `#13112B` للوضوح والتباين العالي المقروء (`--text-primary: #13112B;`).
- **النصوص الثانوية:** `#6E6D7A` للمعلومات التكميلية والميتاداتا (`--text-muted: #6E6D7A;`).

## 4. لغة التصميم وتجربة المستخدم (UI/UX Style Language)

### 1. واجهات الكتل المنظمة (Bento-Box UI)
- استبدال القوائم المنسدلة التقليدية بكتل وبطاقات شبكية غير متماثلة ومصممة بعناية (Bento Grid).
- تُستخدم لعرض:
  - فئات وأقسام الكليات والتخصصات الأكثر نشاطاً.
  - الملخصات السريعة في صفحة الملف الشخصي ولوحة التحكم.
  - إحصائيات المعروضات ونسب التبادل المجاني مقابل البيع.

### 2. مؤشرات الحصة البصرية (Quota Ring)
- بدلاً من النصوص الرقمية الجافة للكوتا، يتم استخدام عداد دائري تفاعلي (SVG / CSS Conic Gradient Ring).
- يعرض الحصة المستهلكة من السقف المشترك:
  - للطلاب غير الموثقين: (مثال: `2 / 3` إعلانات نشطة).
  - للطلاب الموثقين: (مثال: `4 / 5` إعلانات نشطة).
- يتغير لون العداد الحلقي انسيابياً من النعناعي الكهربائي `#00E5A3` إلى الزعفراني `#FFB800` عند الاقتراب من الحد الأقصى.

### 3. مؤشرات حيوية الحرم الجامعي (Live Campus Pulse Indicators)
- نقاط ومؤشرات تفاعل نابضة باللون الأخضر النعناعي (`pulse-dot` بتأثير CSS keyframe animation).
- تُظهر حيوية التفاعل اللحظي:
  - طلاب نشطون حالياً في نفس الكلية.
  - إعلانات تم نشرها خلال الساعة الأخيرة.
  - حالة المتاجر والمكتبات المفتوحة داخل الحرم الجامعي في الوقت الفعلي.

## 5. قواعد تطبيق الهوية في قوالب Razor و CSS
1. **الالتزام بمتغيرات CSS المركزية:** تُعرّف الألوان الجديدة في `:root` داخل `site.css` وتُستدعى باستخدام `var(--brand-*)`.
2. **التباين وإمكانية الوصول (Accessibility & Contrast):**
   - يُمنع وضع نصوص بيضاء مباشرة فوق لون الألاباستر `#F8F7F4`؛ استخدم دائماً نصوص الأزرق الليلي `#13112B`.
   - عند استخدام أزرار النعناعي الكهربائي `#00E5A3`، يكون لون النص داكناً `#13112B` لتحقيق أعلى نسبة تباين وقراءة مريحة.
3. **أبعاد اللمس Mobile-First:** جميع الأزرار والبطاقات التفاعلية تحتفظ بحد أدنى للارتفاع واللمس 44px مع زوايا منحنية رشيقة (`border-radius: 12px - 18px`).
4. **شارات التوثيق (Trust Badges):** استخدام السماوي المتوهج `#00C2FF` حصراً لعلامات التوثيق الجامعي المعتمد والمكتبات الرسمية.
